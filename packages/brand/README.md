# CreateX brand

The supplied presentation is the visual source for this theme. `assets/createx-logo-original.png` is the image extracted unchanged from its cover; SHA-256: `90ada3e63ba29188526ac069016c074b44101898dce4ebce1674544cc5c49b07`.

Use the original artwork for the header, footer and sharing image. The home hero uses the separately generated city co-creation illustration in apps/website/src/assets/. The browser icon is a crop of the same X. Do not replace it with the former star glyph or redraw the logo. The build produces a WebP for the web while preserving the source PNG.

The presentation uses deep blue `#005C7A`, teal `#009F9D`, coral `#FF5E3A`, charcoal `#3A3A3A`, and light `#FAFAF7`. The interactive teal is darkened to `#007675` so small text and white button labels pass normal-text contrast. Teal and coral from the deck remain decorative brand colors. No remote fonts, trackers or extra services are added.

The full presentation and unrelated workshop photos stay in the project's private reference directory. Only the supplied logo and the approved generated concept illustration are included in the website build; no workshop photos are published.
