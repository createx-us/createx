# CreateX 交互设计

日期：2026-10-29。依赖功能设计01，先于界面实现保存。

## 视觉叙事

暖白纸面、墨黑排版、鲜橙强调、细线网格与城市协作图谱。首页以大标题和抽象城市图谱构成非对称版式；图谱是概念插画，不是已开通节点地图。中段以横向路径、编号手册、开放式文字排版交替，避免全部卡片。细节页采用清晰章节、侧注与有节制的色块。系统字体无外部字体依赖。

## 导航

桌面固定页头：品牌、实践、城市、伙伴、资料、语言与加入。当前页aria-current。手机折叠菜单保持44px触达，按钮公开expanded/controls状态；Escape关闭并还焦点，选链接后关闭。跳到正文链接。页脚提供所有页面与版本信息。

## 语言

每个页面具有en/zh一一对应路径，语言切换保留页面及当前章节hash。锚点ID跨语言一致；独立meta、canonical、og、hreflang、lang。默认入口为英文，可明确切换中文，无强制定位跳转。

## 加入路径

1. 选角色 → 页面内定位本地申请工具。
2. 填城市/投入时间/真实议题/贡献证据/所需支持；不要求身份证、资产、密码或付款。
3. 本地校验必要字段与长度 → 下载纯文本申请摘要。
4. 可见状态为‘已生成下载，尚未发送’；不假装提交。页面始终说明尚未接入收件渠道，数据不上传也不持久保存，清空可重置。

## 资源、FAQ与异常

资源链接直接下载对应语言的公开内容摘要与模板。FAQ采用原生details，键盘Enter/Space可展开。外链标明来源及访问要求，不以内部文件链接替代公开资源。未知URL返回404并提供两语言主页。无JS时所有正文/导航/下载可用，申请工具给出静态模板备用。

## 验收场景

中英文桌面/手机、所有导航与返回、章节语言切换、移动菜单与Escape、下载内容、申请空值/合法值/重置、键盘焦点、无横向溢出、减少动态、真实404、TLS与版本。截图仅保存页面公开内容，不包含账户或私人资料。
