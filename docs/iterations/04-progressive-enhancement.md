# 04 — 无JS与隐私边界

目标：让移动导航与加入入口在脚本不可用时仍安全可用。

改动：增加noscript完整导航；本地申请fieldset和生成按钮默认禁用，脚本完成事件绑定后才启用；无JS使用空白模板。隐私说明改成准确的‘不上传、不使用持久存储，完成后清空’，避免错误保证浏览器返回不会恢复数据。

验收：npm run check通过；Chrome刷新显示新版隐私说明，字段和下载工具正常出现；源码明确包含noscript导航及disabled初态。无JS的整页浏览器仿真尚未运行，未据源码检查声称完成真实无JS浏览测试。
