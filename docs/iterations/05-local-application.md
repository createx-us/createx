# 05 — 申请草稿的真实状态与安全边界

目标：明确区分生成、下载和发送，并验证必填与清空。

改动：生成后展示可见的‘保存草稿文本文件’链接，不再隐式自动点击下载；编辑/更换角色会撤回旧草稿，清空时释放临时文件；不联网、不写持久存储。保留最大长度、必填及纯空格校验，内容作为纯文本。

验收：真实Chrome完成空字段及纯空格尝试，两者显示必填提示且无成功状态。自动下载验收时浏览器连接中断，结果不确定，随后改成显式下载链接。独立jsdom行为测试覆盖中英文角色选择、空格拒绝、文件实际文本含所选角色与输入、HTML样文本不执行、编辑撤回和重置；npm run check通过9项测试。没有把模拟DOM测试记为真实浏览器下载验收。

缺口：显式链接实际浏览器下载、中文桌面和手机仍待浏览器恢复后验收。
