# 01 — 公开内容与静态基线

目标：把源文档转成中英文等价的公开叙事，并建立可扩展monorepo。

改动：创建 apps/website、packages/brand；14个语言页面；Workshop OS、城市试点、五角色、伙伴、治理、FAQ与8份公开TXT资源；本地申请生成工具；原始资料排除发布。功能与交互设计已先保存。

验收：首轮 npm run build 成功输出14页；TypeScript严格检查通过；真实Chrome加载英文首页并读取全部导航和内容。标准ESLint替换初版过于简单的自制检查（自查发现其会匹配自身字符串）。

缺口：首页大屏标题自然换行形成三行，概念图figure默认margin压缩画幅；需视觉校正。还需真实手机、表单、下载、SEO与线上验证。未发布。
