# CreateX monorepo

CreateX is a city-based innovation culture and practice network. This repository hosts independently deployable projects and shared packages. The first app is the English/Chinese public website.

```
apps/
  website/             Static bilingual official website
packages/
  brand/               Shared identity, colors, release version
docs/
  design/              Product and interaction design
  iterations/          Ten rounds: goals, changes, verification, gaps
  operations/          Deployment and rollback evidence
documents/
  private/             Local source archive, excluded from Git and releases
scripts/               Repository tooling and local preview
```

Use Node 22.18 or newer. From the repository root:

```sh
npm ci
npm run check
npm run dev
```

The preview runs at `http://127.0.0.1:4173`. Build output is `apps/website/dist`; upload only this directory. English and Chinese URLs are `/en/` and `/zh/`, with equivalent subpages. New projects belong in `apps/<name>` with their own package, commands, and deployment boundary. Reusable code belongs in `packages/<name>`; use workspace dependencies instead of cross-app imports.

The application helper creates a text draft on the visitor’s device. No receiving channel is configured, no data is submitted, and no backend, account, analytics, payment, or database is required.

`documents/private`, `.source`, backups, credentials, and original strategy or agreement documents must never be added to a public commit or deployment. Public resources are reviewed summaries generated by the website build. Historical plans and proposed governance mechanisms are not represented as current operations or issued rights.

The target repository is `createx-us/createx`. Production domain: `createx.us`. Existing repository visibility is preserved.
